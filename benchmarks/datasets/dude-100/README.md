# DUD-E Diverse: 100 prepared cases

Version `dude-diverse-100-v1`, copied from the original multicore benchmark: 20 cases each for AMPC, CXCR4, GCR, HIVPR and HIVRT. The 155 prepared files include ligands, receptors, box configurations and affinity maps. Preparation has not been independently audited. Input bytes are preserved.
